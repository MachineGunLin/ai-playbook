# AI Playbook

本地知识库：遇到任务时快速知道“怎么做、用什么、高手怎么做、有何可复用”。

## 我要做什么 → 打开哪个文件

| 我要… | 打开 |
|---|---|
| 写代码/改仓库/修 bug | `02-playbooks/coding.md` |
| 写文章/改稿 | `02-playbooks/writing.md` |
| 查资料/做调研 | `02-playbooks/research.md` |
| 看图/做图/看视频 | `02-playbooks/image-video.md` |
| 学东西（备考/啃书） | `02-playbooks/learning.md` |
| 查某工具能干嘛、命令怎么敲 | `01-tools/ai-agents.md` |
| 照着做：debug/审查/交接/长任务 | `04-recipes/` 对应文件 |
| 复制 Prompt | `05-prompts/prompt-library.md` |
| 理解 skill/外壳/多 agent/上下文/记忆 | `03-agent-systems/`（`skills.md`/`harness.md`/`multi-agent.md`/`context.md`/`memory.md`） |
| 踩坑了 | `06-troubleshooting/troubleshooting.md` |

## 规则

- 按任务组织，不按厂商。工具会变，workflow 优先。
- 高频放前面，低频给链接；不为填满而写废话。
- 官方方法与社区经验分开写；单次见闻不收录。
- 旧大文档 `AI_Agents_Guide.md` 仍在原处，本库从它迁移精华，原文件不动。
